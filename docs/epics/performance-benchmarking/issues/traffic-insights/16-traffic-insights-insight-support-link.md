# Generated insight — `Learn more` support link and the AI-generated label

GitHub issue: [#13953](https://github.com/google/site-kit-wp/issues/13953)

## Feature Description

Readers must be told that the insight is written by AI. This issue adds a `Learn more` link to the teaser on the Traffic Overview tab (#13947) and to the insight block on the Typical Traffic tab (#13948). The link opens a support page that explains what the insight is, how it is generated, and that it is generated by AI. The support team writes this page before the rollout. The link is built with `getDocumentationLinkURL()` on `core/site`, with a new slug that is added together with the link.

Link to the design doc: https://docs.google.com/document/d/1dsEs6-NjlP_LNqz5md5fnJMuxh9Vd9f88w4DTrZdLok/edit?pli=1&tab=t.ti7yrmnh2lrv#heading=h.xai0p0vhie15 (see "Documentation in-product" and "Accessibility (a11y)")

## Acceptance criteria

* With `trafficInsights` enabled, the teaser and the insight block each show a `Learn more` link, as in the design.
* The link opens the Site Kit support page for the insight in a new tab.
* The teaser and the insight block each say in text, not only with an icon, that the text is generated by AI.
* The link and the text are shown only when the teaser or the insight block is shown.
