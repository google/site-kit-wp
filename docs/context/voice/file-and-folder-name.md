# A file or folder name

## What the reader does next

The person reads the name in a folder listing, in a path or in a failure report, and picks the file they need. They see the name beside every other name in the folder, and nothing else. A name that could be any of them makes them open each one.

## The rule

Name the thing in a plain word, or in a few plain words joined by hyphens. The test is that a reader who has never opened the file knows from the listing what it holds. A PHP class file takes its name from the class, as `docs/context/php/naming-conventions.md` says.

## One example from Site Kit

The owner puts one text here that a person corrected, from Site Kit's own issues, pull requests or reviews. It has three parts, each on its own line. The request, in one line. The text, as it read after the correction. One sentence on why it is right.

## Where the example came from

The issue, the pull request or the review the text came from, by its number.
