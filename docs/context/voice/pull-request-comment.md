# A pull request comment

## What the reader does next

The author of the change reads a comment and decides whether to worry. A reviewer reads the author's answer and decides the same. Each of them wants the cause, and neither wants the search that found it.

## The rule

Name the cause in the fewest words, and stop. The test is that no sentence says how the cause was found. A sentence that opens on what was read, counted or compared is the search, so it goes. The sections of a pull request body come from `.github/PULL_REQUEST_TEMPLATE.md`.

## One example from Site Kit

The owner puts one text here that a person corrected, from Site Kit's own issues, pull requests or reviews. It has three parts, each on its own line. The request, in one line. The text, as it read after the correction. One sentence on why it is right.

## Where the example came from

The issue, the pull request or the review the text came from, by its number.
