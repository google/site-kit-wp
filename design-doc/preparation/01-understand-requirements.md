# Design doc preparation

## Introduction

Read ./design-doc/preparation/00-introduction.md

## Preparation

To prepare for creating the design doc, you need to read and understand the requirements.

Read the PRD and Figma design, and write an overview of the feature:

- Create a new directory in ./design-doc/preparation/output/overview-XX where XX is the latest iteration number.
- Write the overview to ./design-doc/preparation/output/overview-XX/overview.md
- Save screenshots from Figma to ./design-doc/preparation/output/overview-XX/screenshots/
- Copy this file (01-understand-requirements.md) and 00-introduction.md to ./design-doc/preparation/output/overview-XX/

DO NOT read the contents of the previous iterations' output directories, as they may be incorrect.
