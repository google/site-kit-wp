# Design doc preparation

## Introduction

Read ./design-doc/preparation/00-introduction.md

## Inputs

Read the feature brief (./design-doc/input/feature-brief.md) and, from its "Resources"
section, the PRD and the design.

## Preparation

To prepare for creating the design doc, you need to read and understand the requirements.
Write an overview of the feature:

- Create a new directory in ./design-doc/preparation/output/overview-XX where XX is the next iteration number.
- Write the overview to ./design-doc/preparation/output/overview-XX/overview.md
- Save screenshots from the design to ./design-doc/preparation/output/overview-XX/screenshots/
- Copy this file (01-understand-requirements.md), 00-introduction.md and the feature brief to ./design-doc/preparation/output/overview-XX/
- Update the "Requirements overview" row of the brief's "Current inputs" table to point at the new overview.

DO NOT read the contents of the previous iterations' output directories, as they may be incorrect.
