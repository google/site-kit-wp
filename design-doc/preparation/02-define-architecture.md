# Design doc - architecture

## Introduction

Read ./design-doc/preparation/00-introduction.md

## Inputs

Read the feature brief (./design-doc/input/feature-brief.md) and, from its "Current inputs"
table, the requirements overview.

## Architecture

Define the core architecture for the feature.

- Create a new directory in ./design-doc/preparation/output/architecture-XX where XX is the next iteration number.
- Write the architecture to ./design-doc/preparation/output/architecture-XX/architecture.md
- Copy this file (02-define-architecture.md), 00-introduction.md and the feature brief to ./design-doc/preparation/output/architecture-XX/
- Update the "Architecture" row of the brief's "Current inputs" table to point at the new architecture document.

DO NOT read the contents of the previous iterations' output directories, as they may be incorrect.
