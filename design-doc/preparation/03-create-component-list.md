# Design doc - components

## Introduction

Read ./design-doc/preparation/00-introduction.md

## Inputs

Read the feature brief (./design-doc/input/feature-brief.md) and, from its "Current inputs"
table, the requirements overview and the architecture document.

## Component list

Create a list of React components for the feature.

- Create a new directory in ./design-doc/preparation/output/components-XX where XX is the next iteration number.
- Write the component list to ./design-doc/preparation/output/components-XX/components.md
- Copy this file (03-create-component-list.md), 00-introduction.md and the feature brief to ./design-doc/preparation/output/components-XX/
- Update the "Component list" row of the brief's "Current inputs" table to point at the new component list.

DO NOT read the contents of the previous iterations' output directories, as they may be incorrect.
