# Design doc - detailed design outline

## Introduction

Read ./design-doc/preparation/00-introduction.md

## Inputs

Read the feature brief (./design-doc/input/feature-brief.md) and, from its "Current inputs"
table, the requirements overview, the architecture document and the component list.

## Detailed design outline

Create an outline for the detailed design section of the design doc.

The output should be a skeleton of the detailed design section, just the sub-section headings with a VERY brief description of each section.

- Create a new directory in ./design-doc/preparation/output/outline-XX where XX is the next iteration number.
- Write the outline to ./design-doc/preparation/output/outline-XX/outline.md
- Copy this file (04-create-detailed-design-outline.md), 00-introduction.md and the feature brief to ./design-doc/preparation/output/outline-XX/
- Update the "Detailed design outline" row of the brief's "Current inputs" table to point at the new outline.

DO NOT read the contents of the previous iterations' output directories, as they may be incorrect.
