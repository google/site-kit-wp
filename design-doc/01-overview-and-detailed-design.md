# Design doc - overview and detailed design

## Introduction

Read ./design-doc/preparation/00-introduction.md

## Inputs

Read the feature brief (./design-doc/input/feature-brief.md) and, from its "Current inputs"
table, whichever preparation artifacts it names — the requirements overview, the architecture
document, the component list and the detailed design outline.

The design doc follows the template ./design-doc/input/design-doc-template.md. Example design
docs, for structure and depth, are in ./design-doc/input/examples/

## Design doc content

Write all sections up to and including the detailed design section of the design doc.

- Create a new directory in ./design-doc/output/iteration-XX where XX is the next iteration number.
- Write the design doc to ./design-doc/output/iteration-XX/design-doc.md
- Copy this file (01-overview-and-detailed-design.md), ./design-doc/preparation/00-introduction.md and the feature brief to ./design-doc/output/iteration-XX/
- Update the "Design doc" row of the brief's "Current inputs" table to point at the new design doc.

DO NOT read the contents of the previous iterations' output directories, as they may be incorrect.
