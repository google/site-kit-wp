# Site Kit by Google

Site Kit is a one-stop solution for WordPress users to use everything Google has to offer to make them successful on the web.

Learn more: [https://sitekit.withgoogle.com](https://sitekit.withgoogle.com)

## Contributing

We welcome feature requests and bug reports through [our official support forum on WordPress.org](https://wordpress.org/support/topic/read-first-welcome-to-the-site-kit-support-forum-5/) where we actively monitor and reply to all topics.

For reports of a security-related nature, please refer to [our security policy](https://github.com/google/site-kit-wp/security/policy).

While we'd like to accept third-party code contributions, we are a large team with an established, pre-planned, regimented workflow that includes tools that are not available to external contributors. For this reason, we are unable to review community pull requests.

## Requirements

* WordPress >= 5.2
* PHP >= 7.4

Test for Gemini Code Assist
